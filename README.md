# Инвестор — тренажёр инвестиционных решений

Небольшое браузерное приложение для обучения основам управления инвестиционным портфелем. Работает без сервера, регистрации и API.

## Возможности

- виртуальный стартовый капитал от 500 000 до 5 000 000 ₽;
- три стартовые стратегии: осторожная, сбалансированная и стратегия роста;
- выбор допустимой просадки и длительности игры;
- акции, облигации, золото и денежный резерв;
- 12 условных рыночных сценариев;
- покупка и продажа активов, ребалансировка;
- автоматический пересчёт портфеля;
- сохранение прогресса в браузере (`localStorage`);
- экспорт истории в CSV;
- адаптивный интерфейс для телефона и компьютера.

## Запуск локально

Открой `index.html` в браузере. Никакой сборки не требуется.

## Публикация на GitHub Pages

1. Создай новый публичный репозиторий на GitHub, например `investor-trainer`.
2. Загрузи в корень репозитория `index.html` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. Через минуту GitHub Pages покажет адрес опубликованного приложения.

## Важные ограничения модели

Все сценарии доходности заданы вручную и являются учебными. Это не реальные котировки, не прогноз и не инвестиционная рекомендация. Пока не моделируются комиссии, налоги, инфляция, купоны, дивиденды, дефолты и ликвидность отдельных выпусков. Ребалансировка проводится без торговых издержек. Приложение не подключается к брокеру и не совершает реальные сделки.

## Данные и приватность

Прогресс хранится локально в браузере пользователя. Данные никуда не отправляются. Очистка данных сайта/браузера может удалить сохранённую игру.
